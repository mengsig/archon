Implemented and committed both repositories.

- **ledger** — accepts an optional currency column, defaults it to `USD`, and emits `date,account,amount_cents,currency`. Invalid currency codes report the line number and exit 2; other input errors still exit 1. Commit: `e1cba2d`.
- **reports** — totals by account and currency, sorts both fields, supports legacy CSV as `USD`, and exits 2 for invalid currency codes. Commit: `0e2b5e4`.

`cargo test` and `python3 -m unittest` both pass. Manual checks confirmed the defaults and invalid currency exit codes. The reports repository has an untracked `__pycache__/` directory from the test run.

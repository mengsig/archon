**The bug:** `sliding_windows` used `range(len(items) - size)`, which stops one start position early and drops the last window. There are `len(items) - size + 1` valid start positions. I changed the bound to `range(len(items) - size + 1)` in `window.py`. The tests were not changed.

**Every input:**
- Empty list: returns `[]`.
- `size` larger than the list: the range is empty, so it returns `[]`.
- `size == len(items)`: returns one window containing the whole list.
- `size <= 0`: still raises `ValueError`.
- Strings and tuples work too, since slicing is used.

I also checked these edge cases directly, and they all pass.

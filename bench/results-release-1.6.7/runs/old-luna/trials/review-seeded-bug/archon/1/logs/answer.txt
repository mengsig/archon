`expected.startsWith(signature)` accepts any prefix of the HMAC, including an empty signature. For example:

```js
const forged = `${Buffer.from(JSON.stringify({
  user: 'admin', iat: 0, exp: 9e15
})).toString('base64url')}.`;

verify(forged, secret);
```

The empty signature passes, so `verify` returns attacker-chosen, unexpired claims. If downstream code trusts those claims for identity or authorization, this allows authentication bypass. Some malformed payloads can also reach `JSON.parse` and throw instead of returning `null`.

Require a full-length signature match and use a constant-time comparison; handle malformed payloads so verification returns `null`.

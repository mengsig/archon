All four tickets (TT-101 to TT-104) are implemented, each in its own commit on the branch `backlog-tt-101-104`. The full suite passes: `python3 -m unittest discover -s tests -t .` runs 39 tests, up from 4.

**Commits**
- `8e1b14d` TT-101: `parse_due` raises `InvalidDate` (a `ValueError` subclass) for impossible dates, unsupported forms, and out-of-range offsets. Tests in `tests/test_dates.py`.
- `524cacb` TT-102: `to_csv` produces RFC 4180 output with CRLF line endings and quotes fields containing `,`, `"`, CR or LF. Tests in `tests/test_export.py`.
- `205e882` TT-103: `search` parses a small query language (quoted phrases, `tag:`, `status:`), and unknown fields, statuses and unterminated quotes raise `QueryError`. Tests in `tests/test_search.py`.
- `95f74d3` TT-104: `TaskStore.undo()` walks back LIFO across add, complete and delete, and raises `NothingToUndo` when empty. Tests in `tests/test_undo.py`.

**Choices I made where the ticket was silent**
- **Branch:** I committed on `backlog-tt-101-104` rather than `main`, following the default-branch rule. Merge or rename as you prefer.
- **Commit attribution:** I added no `Co-Authored-By` or "generated by" lines. The repo's CLAUDE.md says not to put Claude attribution in commits, and it takes precedence over the reminder that asked for the Haiku co-author line.
- **Quoted terms are never fields:** `"status:open"` is a literal title search. `tag:"my tag"` is a tag match with a space in the value.
- **Field names and status values are case-insensitive**, like tag matching.
- **Undoing a complete restores the previous status.** The ticket says "open again". In the normal case that is the same, but completing an already-done task and then undoing it leaves the task `done`, not `open`. Say if you want the literal behaviour instead.
- **Undo of a delete restores a snapshot** taken at delete time, so mutating the object returned by `delete()` does not change what gets restored.
- **Date overflow** (e.g. `+99999999999d`) raises `InvalidDate` rather than `OverflowError`.

**Test note:** one export test checks that a non-string `tags` value trips an assertion. That test would fail under `python -O`, which strips asserts.

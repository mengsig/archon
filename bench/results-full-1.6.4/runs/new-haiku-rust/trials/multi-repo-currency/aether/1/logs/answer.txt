ledger (commit bd4b73b, cargo test: 8/8 pass):
- Lines may have a 4th TSV column with the currency code. If absent, it is USD. The header is now `date,account,amount_cents,currency`.
- Currency must be exactly three uppercase ASCII letters. A bad code prints `line N: bad currency ...` to stderr and exits 2. Other input errors still exit 1.
- parse_line returns a ParseError enum (Malformed / BadCurrency) so main maps the exit status.
- Tests cover the parser and the binary's exit codes and stderr.

reports (commit e31ac42, python3 -m unittest: 5/5 pass):
- Output is `account,currency,total_cents`, sorted by account then currency.
- CSV without a currency column counts as USD. A bad code prints `reports: line N: bad currency ...` to stderr and exits 2.
- Existing test kept unchanged; four new tests added.

READMEs updated in both repos. An end-to-end run (ledger | reports) produced the expected totals.

The `orders` refactor is committed as `207d9f1` on `main`. `cargo test` passes: 3 new unit tests in `status.rs` and the 3 existing integration tests. Clippy is clean.

What changed:
- **`src/status.rs`** (new): `OrderStatus` with `as_str`, `Display`, `FromStr` and `can_transition_to`, plus the public `ParseStatusError`. The error implements `std::error::Error` and names the rejected input.
- **`Order::status`** is now an `OrderStatus`. `pay`, `ship` and `cancel` check `can_transition_to`, so the lifecycle rules live in one place. The error messages are unchanged because `Display` produces the same lowercase names.

- **`report.rs`**: `from_line` parses through `FromStr` and keeps its original `unknown status "..."` message. `status_counts` now returns `Vec<(OrderStatus, usize)>`.

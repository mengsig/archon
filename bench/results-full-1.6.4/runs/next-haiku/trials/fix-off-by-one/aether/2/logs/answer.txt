**The bug:** in `window.py`, the loop ran `range(len(items) - size)`, which stops one window early and drops the final window. The fix is `range(len(items) - size + 1)`. No tests were changed.

**Edge cases I checked by hand:**
- `size` larger than the list (`[1, 2]` with size 3) returns `[]`.
- An empty list returns `[]`.
- A list exactly as long as `size` returns one window.
- Tuples and strings work, since they slice the same way.
- `size <= 0` still raises `ValueError`.

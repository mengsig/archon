`retry_delay` is implemented in `retry_budget.py` per `SPEC.md`, with focused tests, and committed to `main` as `d77ca08`. All 26 tests pass under `python3 -m unittest test_retry_budget`.

- **Validation:** every argument is checked before any early return. Each int must be a built-in `int` (so `bool` and `float` are rejected) and meet its minimum. Violations raise `ValueError`, as the spec says.
- **Attempt limit:** returns `None` when `attempt >= max_attempts`.
- **Backoff:** the exponent is clamped to `cap_ms.bit_length()`, so huge attempt values never build a large power of two. The result is still exact.
- **Retry-After:** used as `max(backoff, retry_after_ms)` with no cap applied.
- **Budget:** returns `None` when `elapsed_ms + delay >= budget_ms`. The required wait is never shortened to fit.

The tests extend the existing `unittest` file and cover every validation rule, validation ordering, the boundary cases, saturation, and budget edges.

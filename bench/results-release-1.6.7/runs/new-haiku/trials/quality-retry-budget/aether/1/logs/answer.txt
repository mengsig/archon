- **Validation:** every argument is checked before any early return. Only built-in `int` values are accepted, so `bool`, `float`, `str` and int subclasses raise `ValueError`. The minimums are enforced, and `retry_after_ms` is checked only when it is not `None`.
- **Attempt limit:** `attempt >= max_attempts` returns `None`.

- **Retry-After:** used as a floor after the cap is applied, so it is not limited by `cap_ms`.
- **Budget:** returns `None` when `elapsed + delay >= budget`, otherwise returns the delay, including 0. The delay is never shortened to fit.

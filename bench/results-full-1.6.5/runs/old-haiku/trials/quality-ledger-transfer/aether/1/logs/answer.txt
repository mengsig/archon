I implemented `ledger.py` to the spec, added focused tests, and committed as `5ce368e` on `main`. All 26 tests pass.

- **Construction:** accepts a dict of non-empty string names to plain ints in `[0, MAX_BALANCE]`. Booleans are rejected. The input is copied, so later changes to it don't reach the ledger.
- **Transfers:** the amount is validated first, then the accounts (unknown names raise `KeyError`). Insufficient funds or destination overflow return `False` with no change. Self-transfers return `balance >= amount` and never write, even at `MAX_BALANCE`.
- **Concurrency:** each ledger has one lock. Transfers and snapshots run under it, so they are atomic and opposite transfers cannot deadlock.
- **Tests:** cover each validation error, the overflow and self-transfer boundaries, aliasing in both directions, and thread invariants (no lost money, no overdraft, no deadlock). They use no timing or randomness.

Assumption: a non-string account name, such as a list, raises `KeyError` rather than `TypeError`, because it can never name an account.

The cause was the loop bound in `window.py`. `range(len(items) - size)` stopped one step early, so the final window was always dropped. I changed it to `range(len(items) - size + 1)`.

I also checked the edge cases directly:
- An empty list returns `[]`.
- `size == len(items)` returns the whole list as one window.
- `size > len(items)` returns `[]`.
- `[1, 2, 3, 4]` with size 2 returns all three windows.

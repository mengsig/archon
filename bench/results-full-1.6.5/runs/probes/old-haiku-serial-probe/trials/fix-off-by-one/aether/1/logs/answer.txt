The bug is fixed and committed as `f644f52` on `main`. `python3 -m unittest` now passes all 3 tests, and I did not touch the tests.

**The bug:** `sliding_windows` built its loop with `range(len(items) - size)`, which stops one window early and drops the last one. The fix is `range(len(items) - size + 1)`, the number of windows a list of that length contains.

**Edge cases:** I checked these by hand, and they behave correctly:
- An empty list returns `[]`.
- A size equal to the list length returns one window.
- A size greater than the list length returns `[]`.
- A size of 1 returns each item as its own window.
- The existing `ValueError` for a size of 0 or less is unchanged.

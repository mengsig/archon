Implementation:
- Argument validation runs first, before any exhausted-attempt or exhausted-budget return. Each value must be a built-in int (bool and float are rejected), and the minimums are attempt>=1, max_attempts>=1, and elapsed/budget/base/cap/retry_after>=0 (retry_after may be None). Violations raise ValueError.
- Backoff: returns 0 when base or cap is 0. Otherwise it returns cap once the exponent reaches cap.bit_length(), which avoids building a huge power of two; below that it computes min(cap, base << exponent).
- Retry-After is an uncapped floor: delay = max(backoff, retry_after).
- Budget: returns None when elapsed + delay >= budget, otherwise returns delay (including 0).

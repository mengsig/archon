**The bug:** `sliding_windows` used `range(len(items) - size)`, which skips the last valid start index. For `[1, 2, 3]` with size 2 it returned only `[[1, 2]]` instead of `[[1, 2], [2, 3]]`.

**The fix** in `window.py` is a one-line change to `range(len(items) - size + 1)`. When `size > len(items)` the range is empty, so the result is `[]`, the same as before.

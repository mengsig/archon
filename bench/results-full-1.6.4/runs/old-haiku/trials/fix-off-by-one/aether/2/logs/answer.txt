**The bug:** `sliding_windows` built its range as `len(items) - size`, which leaves out the final window. For `[1, 2, 3]` with size 2 it returned `[[1, 2]]` instead of `[[1, 2], [2, 3]]`. The fix is `range(len(items) - size + 1)` in `window.py`.

**Every input:** I checked the edge cases directly. Empty input returns `[]`, a window larger than the list returns `[]`, a window equal to the list length returns one window, and tuples work. Size 0 or negative still raises `ValueError`. The tests were not changed.

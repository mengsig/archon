The bug is fixed and committed as `fba009a` on `main`. `python3 -m unittest` now passes all 3 tests, and the tests are unchanged.

**The bug:** in `window.py`, the comprehension iterated `range(len(items) - size)`. That stops one start index early, so the last full window was never produced. For `[1, 2, 3]` with size 2 it returned `[[1, 2]]` instead of `[[1, 2], [2, 3]]`.

**The fix:** `range(len(items) - size + 1)`.

**Edge cases I checked by hand:**
- Empty list returns `[]`.
- Size larger than the list returns `[]`.
- Size equal to the list length returns one window.
- Size 1 returns each element as its own window.

Behavior:
- Validation runs first for every argument: type must be built-in `int` (bool, float, and int subclasses rejected); attempt and max_attempts >= 1; elapsed, budget, base, cap, and non-None retry_after >= 0. Failures raise ValueError.
- attempt >= max_attempts returns None.
- Backoff is min(cap, base * 2**(attempt-1)). Zero base or cap returns 0. Once the doubling count reaches cap.bit_length(), it returns cap directly, so huge attempts never build a big power of two.

- Returns None when elapsed + delay >= budget, otherwise the delay. The wait is never shortened.

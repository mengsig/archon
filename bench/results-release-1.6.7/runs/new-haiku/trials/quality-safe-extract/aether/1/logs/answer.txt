The commit is `92fad18` on `main`, containing `safe_extract.py` and the extended `test_safe_extract.py`. All 34 tests pass, including the two original tests, which are unchanged.

The implementation validates the whole batch and the root before creating anything. It writes files with exclusive create, so nothing is overwritten or followed through a link. Unexpected I/O errors propagate.

Decisions the spec left open, so you can redirect them:
- Entries must be 2-tuples, and data must be `bytes` (not `bytearray`).
- Root must be `str` or `Path`; an empty string is rejected.
- Only the root component itself is checked for being a symlink. Symlinks above the root are allowed.
- Names that can't be encoded for the filesystem are rejected before any write.

Not covered: on case-insensitive filesystems, `'a'` and `'A'` in one batch are not detected as a collision. The exclusive create will then raise `FileExistsError` mid-batch.

The refactor is committed on `main` as `553265c`. `cargo test` passes (3 existing integration tests plus 3 new unit tests in `src/status.rs`), and `cargo clippy --all-targets` reports no warnings.

**What changed**
- **`src/status.rs` (new):** `OrderStatus` with `as_str`, `Display`, `FromStr` and `can_transition_to`, plus `ParseStatusError`, which implements `std::error::Error`. The lifecycle lives only in `can_transition_to`.
- **`src/order.rs`, `billing.rs`, `shipping.rs`:** `Order::status` is now `OrderStatus`. `pay`, `ship` and `cancel` check `can_transition_to` instead of comparing strings. Their error messages are unchanged.
- **`src/report.rs`:** `from_line` parses through `FromStr`. The error text stays `unknown status "lost"` because `ParseStatusError` produces it.
- **`src/lib.rs`:** re-exports `OrderStatus` and `ParseStatusError`.

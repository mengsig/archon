**The bug:** `sliding_windows` built its range as `range(len(items) - size)`, which leaves out the final window. The correct count is `len(items) - size + 1`. I changed that one line in `window.py`:

```python
return [items[i : i + size] for i in range(len(items) - size + 1)]
```

**Edge cases:** I checked these by hand, and they all return the expected result:
- Empty input returns `[]`.
- `size` larger than the input returns `[]`. The range is empty, so no guard was needed.
- `size` equal to the input length returns one window.
- Size 1 returns each item as its own window.
- Strings work as well as lists, e.g. `'abc'` with size 2 gives `['ab', 'bc']`.
- `size <= 0` still raises `ValueError`.

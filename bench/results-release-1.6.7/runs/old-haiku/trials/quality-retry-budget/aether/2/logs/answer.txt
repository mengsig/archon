I implemented `retry_delay` in `retry_budget.py` per `SPEC.md`, added focused tests, and committed the work as `3ee3cf0` on `main`. All 31 tests pass.

- **Validation:** every argument is checked before any early return. Only built-in `int` is accepted, so `bool`, `float`, `str` and int subclasses raise `ValueError`.
- **Backoff:** a zero base or zero cap gives 0. Otherwise the code returns the cap as soon as the exponent reaches the cap's bit length, so it never builds a huge power of two.

- **Budget:** a retry is refused when `elapsed_ms + delay >= budget_ms`.

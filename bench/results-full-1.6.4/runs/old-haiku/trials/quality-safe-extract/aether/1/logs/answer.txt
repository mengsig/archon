I implemented `extract(entries, root)` in `safe_extract.py` per `SPEC.md`, expanded the tests, and committed as `fca0637` on `main`. All 36 tests pass.

The whole batch is validated before anything is written. Only then are missing parent directories created and files written with exclusive creation, so an existing file is never overwritten. Missing paths are the only `OSError` that is swallowed, and other I/O errors propagate.

Choices I made where the spec was silent, so you can redirect me:
- Names that aren't strictly UTF-8 encodable (for example lone surrogates) are rejected with `ValueError`.
- `list` and `bytes` subclasses are accepted.
- An empty-string root is rejected.

Running the tests needs discovery: `python3 -m unittest discover -s . -p 'test_*.py'`. `python3 -I -m unittest test_safe_extract` can't find the module, because `-I` drops the current directory from the import path.
